Common Questions

Before you travel

These answers explain how Open Routes works today. Some features are simulated for the school project, but the flow is designed like a professional tourism platform.

Bookings

Do I need an account to book a trip?

Yes. Users need to log in before booking so the site can connect the trip request with their account, favorites and saved planning details.

Do tours include transportation?

Most packages include transportation coordination or a recommended transport option. The tour detail page shows what is included before booking.

Can I review my trip before reserving?

Yes. The booking form includes a trip summary with date, number of people, support request, estimated total and reservation deposit before confirmation.

Accessibility

How do I request an interpreter?

You can choose interpreter support during booking or visit the interpreters page from the destination detail page. The team can help confirm availability.

What if I need wheelchair support?

Each destination has an accessibility checklist. You can also select wheelchair or mobility support in the booking form so the team can review route conditions.

What accessibility tools are available?

The floating accessibility button includes high contrast, dark mode and adjustable text size. The voice assistant can also read page content and help users navigate with spoken commands.

Where can I read the accessibility statement?

You can read the full Accessibility Statement to learn about Open Routes' commitment, current tools, known limitations and support contact.

Account Features

Can I save favorites?

Yes. Destinations and interpreters can be saved to My Favorites so users can return to them later while planning.

Where can I change my preferences?

Open the profile menu and choose Settings. There you can manage account, travel, language, notification and privacy preferences.

What happens when I log out?

The site clears the active session on this browser. Favorites and saved demo data may still remain locally depending on the browser storage.

Videos & Guides

Do the videos include sign language?

Yes. The site includes a sign language navigation menu and destination videos where the team has uploaded them.

Do all destinations already have sign language videos?

Not all yet. Destination accessibility cards indicate whether a sign language video is available or should be requested first.

Can I use the site without the voice assistant?

Yes. When the assistant prompt appears, users can choose no and continue using the website normally.
